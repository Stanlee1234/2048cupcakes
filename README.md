# 2048 Cupcakes

Hello! I created a 2048 game about cupcakes. I used html to create it for Hack Club Resolution.

It's basically just 2048, a sliding block game where the goal is to combine numbers to make larger ones and reach 2048, but with cupcakes. To run it, open up the folder in a code editor like VS Code and running 

python -m http.server

This will start the server, and go to http://localhost:8000 to see it work!
